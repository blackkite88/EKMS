# OEM Manual — Alfa Laval STX Series Exchangers

**Applies to:** HX-205, HX-208, HX-401

## Thickness Monitoring
Inspect tube wall thickness per OISD-STD-130. Retirement thickness: 2.0 mm. Clean crude-side fouling each turnaround.
