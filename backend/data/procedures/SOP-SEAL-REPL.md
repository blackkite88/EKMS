# SOP-SEAL-REPL — Mechanical Seal Replacement

**Applies to:** Centrifugal pumps (P-101, P-102, P-210, P-215, P-230)
**Revision:** 3 (2021-06-01)

## Steps
1. Isolate and depressurise the pump. Lockout/tagout.
2. Remove coupling guard and disconnect coupling.
3. Remove the old mechanical seal.
4. Install the new seal per OEM torque spec.
5. Reconnect coupling and replace guard.
6. Restore pump to service and monitor for leaks.

> ⚠️ GAP: This SOP does NOT include the post-replacement shaft alignment verification that the OEM manual (MAN-KSB-RPH200, Section 7.4) marks as MANDATORY. This omission was identified as the root cause of both FAIL-2023-07 (P-102) and FAIL-2025-03 (P-101). A corrective action to update this SOP was raised after FAIL-2023-07 but never completed.

**Related:** MAN-KSB-RPH200, FAIL-2025-03, FAIL-2023-07, P-101, P-102
